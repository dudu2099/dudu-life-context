# 访谈问题

> 说明：方式二访谈用的问题，可以改、可以换顺序、可以加删。规矩写在 `flows/没语料.md` 第 3 步：一次一个，问发生过的事，最多八个，他说够了就停。每个问题后面写了答案多半落到哪个文件，方便写入时对照。

1. **现在最占你时间的一两件事是什么？做到哪一步了？**
   → `01-我是谁/1-基本盘.md`；有具体经过的进 `02-素材/故事库.md`

2. **最近一次纠结了很久的决定是什么？最后怎么选的，为什么？**
   → `01-我是谁/4-做事方式.md`、`01-我是谁/3-信念.md`；整件事进故事库
   追问可以是：当时放弃的那个选项，现在想起来可惜吗？

3. **有没有一件事，你现在想起来挺后悔的，或者挺得意的？**
   → `02-素材/故事库.md`；转折进 `01-我是谁/2-来路.md`

4. **AI 给过你哪种回答让你特别烦？哪种让你觉得「对，就是这样」？**
   → `05-守则/协作偏好.md`

5. **有什么事，是你每次都得重新跟 AI 解释一遍的？**
   → 多半是 `01-我是谁/1-基本盘.md` 或 `05-守则/协作偏好.md`

6. **（不可跳）有没有一段你说过、发过的话，自己觉得挺像自己的？凭记忆打出来就行，口头禅也算。**
   → `01-我是谁/5-表达.md` 的样例。不要求他是会写东西的人。**这一题不可跳**：这是访谈里唯一能拿到原声的地方，没有它「表达」一章就没有样例。他明确说没有，才算了。

7. **有没有哪类事，你绝对不想让 AI 替你做，或者替你做决定？**
   → `05-守则/权限边界.md`、`01-我是谁/3-信念.md`

8. **最近看过、听过的东西里，有没有哪个让你改了想法，或者让你很不同意？**
   → `02-素材/输入库.md`、`02-素材/观点库.md`
